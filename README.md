# Ponto — Oportuniza CSF e CAIS

Sistema de ponto e banco de horas em um único arquivo HTML, sincronizado pelo Firebase.

## Como abrir

Site: https://oportunizaceara.github.io/ponto

No Firebase Console → Authentication → Settings → **Authorized domains**, adicione `oportunizaceara.github.io`. Use `https://`, nunca `file://`.

## O que não vai para o GitHub

Backups JSON e planilhas Excel ficam só no computador (dados de funcionários).
